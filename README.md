## 🍔 Quiosco de Comida (Next.js App Router)

Aplicación web FullStack de un quiosco de comida desarrollada con tecnologías modernas. Permite la gestión completa de órdenes, productos y categorías.

### 🛠️ Tecnologías y Herramientas
* **Framework:** [Next.js](https://nextjs.org) (App Router & Server Actions)
* **Base de datos & ORM:** PostgreSQL con [Prisma](https://www.prisma.io)
* **Validación:** [Zod](https://zod.dev)
* **Estado Global:** [Zustand](https://github.com/pmndrs/zustand)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com)
